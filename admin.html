心得後台

連線到 GitHub

第一次使用：怎麼產生權杖？
  1. 到 GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token。
  2. Repository access 選 Only select repositories → book-notes。
  3. Permissions → Repository permissions → Contents：Read and write，其他維持預設。
  4. 到期日建議 90 天；產生後複製，貼到上面的欄位。權杖只會顯示一次。

權杖只能改 book-notes 這個 repository，不要貼在別的地方。為了安全，後台不會把權杖存在裝置上，每次開新分頁要重新貼一次；可以存在密碼管理工具裡方便取用。
