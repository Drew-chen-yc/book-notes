《慶餘年》結局解析與重雷心得

貓膩

4.5★★★★★☆

2026-10-31 · 約 12 分鐘閱讀

害死葉輕眉的主謀，是范閒的親生父親慶帝。陳萍萍查出真相，用輪椅裡藏的槍刺殺慶帝失敗，被當眾凌遲。范閒帶著從神廟回來、失去記憶的五竹，聯手若若、海棠等人重傷慶帝，慶帝因為好奇揭開五竹的眼罩，被一道光當場擊殺。

先講結論

  • 范閒的親生父親是慶帝，不是司南伯范建。母親葉輕眉跟他一樣，是從另一個時代來的人。
  • 害死葉輕眉的主謀就是慶帝。他刻意把陳萍萍、范建調離京都，再放任皇后家族、長公主和神廟對葉輕眉下手。
  • 陳萍萍查出真相，用葉輕眉留在他輪椅裡的槍刺殺慶帝，重傷了他卻沒能殺死。他被慶帝當眾凌遲，范閒趕到時只來得及讓他死在自己懷裡。
  • 最後一戰，范閒帶著從神廟回來、失去記憶的五竹，加上若若的狙擊、海棠、王十三郎、影子圍攻慶帝。慶帝重傷後，出於好奇伸手揭開五竹的眼罩，被五竹眼中射出的光當場擊殺。
  • 三皇子李承平登基，范閒退出朝堂，帶著林婉兒一家隱居杭州西湖，暗中握著足以影響慶國和北齊的力量。

完整劇情

第一階段：澹州少年

一個臥病在床的年輕人范慎死後醒來，成了被蒙眼少年五竹揹著逃命的嬰兒。他在海邊小城澹州長大，名叫范閒，名義上是京都戶部侍郎范建的私生子，由祖母撫養。五竹教他武功，那門功夫叫霸道真氣；監察院派來的毒師費介教他用毒。

他知道自己的母親叫葉輕眉，是一個改變過整個國家的女人，在他出生不久後死於非命。十六歲那年，京都來人刺殺他，他也被叫回京都。

這段在做什麼：交代范閒能活下來，靠的全是母親留下的人：五竹、費介、還有遠在京都的陳萍萍和范建。他們對他好，都是因為葉輕眉。

第二階段：京都與內庫

范閒進京，被安排娶宰相林若甫的女兒林婉兒，也就是長公主李雲睿的私生女。這樁婚事背後，是葉輕眉當年創辦的內庫財權。長公主掌著內庫，自然把范閒當成眼中釘。

他在京都的詩會上背出前世的詩詞，一夕成名。北齊的文壇大家莊墨韓指控他抄襲，范閒在殿上醉後一口氣背出幾百首詩，從此被稱為詩仙。他也被陳萍萍收進監察院，拿到了提司的腰牌。

這段在做什麼：把范閒放進京都的權力漩渦，也讓他用前世的詩詞換來名聲，這是全書最受爭議、也最有那個年代味道的橋段。太子、二皇子、長公主也在這時各自拉攏或刺殺他，讀者跟著范閒一起摸清每個人的立場。

第三階段：北齊與江南

范閒出使北齊，帶回被北齊關押的間諜言冰雲，結識北齊的聖女海棠朵朵、小皇帝戰豆豆，後來才知道這位小皇帝其實是女扮男裝。他也在北齊見到了大宗師苦荷。

回國後他接掌內庫、下江南，跟長公主一系正面交鋒，在江南建立自己的勢力。途中他在山谷遇伏，差點喪命。很久之後才知道，山谷那場刺殺背後的推手竟是陳萍萍，他借秦業之手逼局勢往前走。

這段在做什麼：范閒從被保護的少年，變成手上有錢、有人、有情報的權臣。他以為自己在下棋，其實一直在別人的棋盤上。

第四階段：身世與大東山

范閒逐漸知道了自己的身世：他是慶帝和葉輕眉的兒子。慶帝對他好，也一次次拿他當棋子試探其他皇子。

接著是大東山祭天。慶帝刻意以身作餌，引北齊的苦荷、東夷城的四顧劍出手，還讓人以為自己死在山上。京都裡的長公主、太子、二皇子趁機謀反。范閒趕回京都平亂，慶帝這才活著回來，露出真面目：他就是隱藏多年的第四位大宗師，在大東山以一己之力重創苦荷和四顧劍。

叛亂失敗，長公主、太子、二皇子先後自盡。

這段在做什麼：把慶帝從一個溫和的皇帝，翻成全書最深不可測的人。所有人都在他的算計之內，包括想反他的人。

第五階段：陳萍萍之死

陳萍萍這一生只認一個人，就是葉輕眉。他一直在查她的死，最後查出主謀就是慶帝。他設局回到京都，面對慶帝，扣下輪椅裡藏著的槍。那把槍是葉輕眉當年留給他的。

慶帝重傷，卻沒有死。陳萍萍被打成階下囚，慶帝替他羅織罪名，當眾凌遲，用珍貴的人參吊著他最後一口氣，還讓他在眾人面前受盡羞辱。范閒一路趕去，還是晚了一步。陳萍萍在秋雨裡死在他最疼惜的那個孩子懷裡，死前知道了葉輕眉那個箱子的真相，臉上還是那副冷傲的神情。

這段在做什麼：全書情緒的最高點，也是陳萍萍這個角色的完成。他坐了一輩子輪椅，最後是站在自己的信念上死的。陳萍萍用自己的死，逼范閒不能再假裝看不見。從這一刻起，范閒跟慶帝徹底決裂。

第六階段：神廟與五竹

決戰之前，范閒和五竹去了神廟。神廟揭開了這個世界的秘密：它是上一個高度發達的文明留下的軍事博物館兼避難所，神廟的使者其實都是機器人，任務是防止人類重蹈覆轍。五竹就是神廟的第一個使者。

葉輕眉給這個世界帶來太多先進的東西，踩到了神廟的底線。神廟想除掉她，五竹卻一直護著她，直到神廟和慶帝聯手。范閒從神廟帶回了一個失去記憶的五竹。

第七階段：最後一戰

范閒回到京都，聯合五竹、若若、海棠、王十三郎、影子圍攻慶帝。若若用葉輕眉留下的重狙擊槍支援，影子為了保護范閒戰死。五竹的武力壓制了慶帝，范閒拼盡全力重創他。

重傷的慶帝最後沒有去殺范閒，而是走向五竹。他一直好奇那條黑布底下是什麼，於是伸手揭開了五竹的眼罩。光從五竹眼中射出，慶帝當場灰飛煙滅。

戰後，范閒的學生三皇子李承平登基。五竹被王十三郎帶回大東山養傷。范閒退出朝堂，帶著家人隱居西湖邊，而北齊的皇帝、聖女、皇妃都跟他有千絲萬縷的關係，天下最強的力量其實握在他手上。

結局解析

慶帝為什麼要殺葉輕眉

慶帝愛葉輕眉，這一點書裡沒有否認。但葉輕眉想要的是一個不一樣的世界，她帶來的技術、制度、思想，最後都會威脅到皇權。慶帝要的是一統天下，而她成了他極權路上最大的障礙。

所以他沒有親手殺她，而是把她身邊最可靠的兩個人調走，讓想殺她的人去動手。事後他照樣對范閒溫和，照樣重用陳萍萍和范建，把所有知情或可能知情的人都放在自己看得到的地方。讀到結局回頭看，前面那些看似寬厚的恩典，其實都是監視。我的理解是，這正是慶帝最可怕的地方：他從頭到尾都很清楚自己在做什麼，也從不後悔。

書名的意思

「慶餘年」可以讀成慶國的餘年，也可以讀成慶幸多出來的人生。范閒前世是病床上等死的人，這一世多活了一次。他一開始只想好好活、好好賺錢、好好愛人，最後卻被母親留下的事、父親的算計推到天下的中心。

結局他殺了慶帝、扶了新君，然後選擇隱居。我覺得這三個字在結尾最清楚：他終於把多出來的這一生，拿回來過成自己的。

陳萍萍算忠臣還是叛臣

陳萍萍是監察院院長，一輩子替慶帝做最髒的事；但他真正效忠的只有葉輕眉。山谷刺殺、各種佈局，他都在推范閒一步步走到能跟慶帝對抗的位置。他的死不是失敗，是最後一步棋。我的理解是，他用自己的死，把范閒推上了那條他自己走不到終點的路。

這是一本穿越小說，還是一本末日小說

神廟的揭密，把整本書的底子翻了過來：這不是古代，而是上一個文明毀滅之後重建的世界。葉輕眉帶來的「新東西」，在這個世界裡其實是舊東西。五竹是機器人，葉輕眉的箱子是狙擊槍。很多讀者讀到這裡才明白，為什麼葉輕眉能知道那麼多、五竹為什麼不會老。

最悲傷的其實是五竹

很多讀者說，全書下場最慘的不是被凌遲的陳萍萍，也不是眾叛親離的慶帝，而是一直陪在范閒身邊、不老不死的五竹。我讀完也有這種感覺。

五竹守了葉輕眉一輩子，沒能救下她；又守了她的兒子二十年，最後連自己是誰都忘了。殺死慶帝的那道光，是他替葉輕眉報的仇，可是他自己大概已經不記得葉輕眉是誰。范閒能退出朝堂、去過自己的日子，五竹卻只能回到大東山，繼續當一個不會老的守護者。

我的理解是，貓膩用五竹寫的是「被留下來的人」。葉輕眉走了，陳萍萍走了，范閒總有一天也會老去，只有五竹會一直在。這讓那個看起來圓滿的西湖隱居結局，底下多了一層說不出口的寂寞。

力量體系與世界觀的最終答案

  • 武力分九品，九品之上是大宗師。天下四大宗師：北齊的苦荷、東夷城的四顧劍、慶國的葉流雲，以及隱藏身分的慶帝。
  • 慶帝是第四位大宗師，一直藏著實力。大東山一戰他重創苦荷和四顧劍，結局時四大宗師三死一走，五竹成了天下武力最強的人。
  • 范閒練的霸道真氣，是五竹從葉輕眉那裡帶來的功法。我的理解是，慶帝的武功也和葉輕眉有關，父子兩人走的是同一條路。
  • 神廟是上一個文明留下的軍事博物館與避難所，使者是機器人，任務是防止人類重蹈覆轍。
  • 葉輕眉留下的箱子是一把重狙擊槍，陳萍萍輪椅裡的槍也是她留下的。這個世界的「神兵」，其實是上一個文明的武器。
  • 監察院和內庫，都是葉輕眉當年建立的，一個是情報與監察，一個是財權。范閒最後同時握住兩者，才有能力反抗慶帝。

伏筆與回收

  • 五竹永遠蒙著黑布、不會老、不記得過去 → 他是神廟的機器人使者，最後殺死慶帝的正是那雙眼睛。
  • 葉輕眉留下的那個神秘箱子 → 是一把重狙擊槍，最後由若若帶上戰場。
  • 陳萍萍從不離身的輪椅 → 裡面藏著葉輕眉留下的槍，他用它刺殺慶帝。
  • 慶帝對范閒一直溫和，看起來只是個好皇帝 → 他是范閒的生父，也是害死葉輕眉的主謀。
  • 慶帝看起來不會武功 → 大東山一戰揭曉，他就是隱藏的第四位大宗師。
  • 范閒在山谷遇伏差點喪命 → 推手是陳萍萍，他借秦業逼范閒成長。
  • 范建和陳萍萍在葉輕眉死時都不在京都 → 是慶帝刻意調開的。
  • 北齊的小皇帝戰豆豆總有些說不出的怪 → 她是女扮男裝的皇帝，後來還為范閒生下女兒。
  • 范閒前世是臥病等死的人，這一世只想好好活 → 結局他放下權力隱居，把多出來的人生過成自己的。
  • 慶帝一再拿范閒試探太子和二皇子，像在磨一把刀 → 他確實在磨刀，只是沒想到這把刀最後會對準自己。
  • 葉輕眉留下的監察院、內庫，表面上都在替慶帝做事 → 最後成了范閒反抗慶帝的本錢。

角色的結局

  • 范閒：殺了慶帝，扶三皇子登基，退出朝堂，隱居杭州西湖，暗中仍握有天下最強的勢力。
  • 慶帝：揭開五竹的眼罩，被一道光當場擊殺。
  • 陳萍萍：刺殺慶帝失敗，被當眾凌遲，死在范閒懷裡。
  • 五竹：從神廟帶回時失去記憶，擊殺慶帝後被王十三郎帶回大東山養傷。
  • 葉輕眉：故事開始前已被害，是全書所有事件的源頭。
  • 林婉兒：范閒的正妻，隨他隱居，生下兒子范良。
  • 柳思思：范閒的妾室，生下長女范淑寧。
  • 戰豆豆：北齊女帝，為范閒生下女兒紅豆飯，繼續以皇帝身分治國。
  • 海棠朵朵：苦荷的傳人，北齊第一高手，參與最後一戰，是范閒的知己。
  • 范若若：用重狙擊槍支援最後一戰。
  • 影子：陳萍萍死後跟隨范閒，最後一戰為保護范閒而死。
  • 長公主李雲睿、太子李承乾、二皇子李承澤：大東山之後的叛亂失敗，先後自盡。
  • 三皇子李承平：范閒的學生，最後登基成為皇帝。
  • 苦荷：大東山被慶帝重創，之後離世。
  • 四顧劍：大東山之戰後也走到生命終點，臨終把希望寄託在范閒身上。
  • 言冰雲：范閒離開後接掌監察院。
  • 范建：辭官，暗中經營葉家留下的力量。

我怎麼看這個結局

我在無雷心得給 4.5 顆星，讀完結局，分數不變。

最打動我的是陳萍萍之死。我在無雷心得說他和慶帝是網文裡最好的兩個配角，結局把這兩個人的對手戲推到頂點：一個用一生替葉輕眉復仇，一個用一生守住自己的天下，誰都沒有退。陳萍萍死在秋雨裡那一段，我讀完很久沒辦法往下翻。

慶帝的死法我很喜歡。他算盡天下，最後不是被打死，而是死於自己的好奇心，死在葉輕眉留下的那個人手上。這個收法既諷刺又合理。

可惜的地方跟當初扣的半顆一樣。范閒身邊高手太多、贏得太順，最後一戰雖然寫得熱鬧，真正一錘定音的還是五竹，主角光環太亮。另外神廟的揭密來得比較晚、交代得不夠多，第一次讀會覺得結局突然從權謀轉成了科幻。無雷心得裡我寫「先暫給 4.5」，讀完結局可以確定，就是 4.5。

讀者吵最兇的地方

  • 慶帝是不是死得太輕鬆：有讀者覺得一代雄主死於好奇心太兒戲；也有人認為這正是貓膩的安排，慶帝這輩子什麼都算到了，唯獨算不到葉輕眉留下的東西。
  • 陳萍萍的死寫得太殘忍：凌遲、示眾、當眾受辱，很多讀者讀到受不了；也有人認為正是這份殘忍，才讓范閒和讀者都沒有退路。
  • 范閒主角光環太強：常見的批評是范閒身世顯赫、身邊全是頂尖高手，最後還要靠五竹收尾；喜歡的人則認為范閒最大的本事本來就是「讓人願意幫他」。
  • 神廟和科幻設定：有讀者覺得權謀小說最後轉成上古文明、機器人和雷射，風格斷裂；也有人很早就從五竹、箱子看出端倪，覺得這是全書最大的伏筆。
  • 范閒隱居算不算逃避：有人覺得他手握天下卻選擇隱居，是負責任的放手；也有人覺得他什麼都沒改變，葉輕眉想要的新世界還是沒有來。
  • 電視劇和原著的差別：電視劇改編讓更多人認識這本書，原著讀者常提醒，劇版很多角色的結局和細節跟小說不同。
